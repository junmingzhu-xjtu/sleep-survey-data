## ⚠️ 数据说明（重要）

本稿件所用数据为 **`generate_demo_data.py` 生成的模拟数据（160 条，`source=demo`）**，
用于课程作业/汇报演示统计分析流程与稿件撰写格式。**稿件按《中华流行病学杂志》格式撰写，
但数据并非真实调查数据**——正式投稿或提交作业前，请用真实收集数据替换
`data/analysis_dataset_160.csv` 后重跑 `analysis.py`，并将文内全部统计数字更新。

数据内在结构：加权日均睡眠时长 Y=(上课日×5+周末×2)/7；7 个维度得分 X1–X7（反向题已转换）；
回归内置了"屏幕使用/学业负担/心理压力/咖啡因/环境为危险因素、运动/作息为保护因素"的关联，
统计结果稳定可复现（固定随机种子 20260826）。
